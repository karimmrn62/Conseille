# Bishop (nom de code)

Conseiller de direction IA à la personnalité de joueur d'échecs visionnaire. Il analyse une situation (mission de conseil, dashboard de performance, projet présenté en comité), propose le coup que personne n'a vu, anticipe la réponse des acteurs et suit les résultats.

Cibles : les consultants d'abord (dont les missions de pilotage de la performance), puis les contrôleurs de gestion, directeurs financiers et managers de réseau.
